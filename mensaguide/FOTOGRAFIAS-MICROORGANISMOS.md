# Fotografías de microorganismos — colección inicial

Descarga [MensaGuide-escritorio-fotos.html](MensaGuide-escritorio-fotos.html) con **Download raw file**. Incluye las herramientas de escritorio anteriores y las fotografías dentro del propio HTML; no hay que descargar una carpeta de imágenes ni conectarse para verlas. El archivo ocupa aproximadamente 23,8 MB.

## Uso y cobertura

- En Microorganismos, una miniatura aparece junto al nombre.
- «Solo con fotografía» muestra las 18 fichas ilustradas de las 890 existentes. Las otras 872 indican expresamente que no hay una imagen disponible en la colección verificada actual.
- Al abrir una ficha ilustrada, se muestra la imagen con identificación, técnica, leyenda, créditos, fuente y licencia. «Ampliar fotografía» abre un visor; puede cerrarse con el botón o con Escape.
- Las fichas de género o complejo identifican la especie usada como ejemplo. Se señalan los cultivos, las imágenes compuestas y las coloraciones; no se atribuyen imágenes de una especie a otras especies.

## Procedencia y licencia

Se utiliza el repositorio oficial del manual **Microbiology**, OpenStax / Rice University, fijado al commit `f91d7fcdc7ebbafa36ec33099f78ff0a494f1c2b`. Cada archivo dispone de una leyenda de origen que permite comprobar su identificación, y se conservan los créditos de CDC, USDA, EPA y los demás que constan en esa versión editorial. No se generan imágenes artificiales.

Las imágenes seleccionadas se reproducen según la licencia **Creative Commons Atribución-NoComercial-CompartirIgual 4.0** indicada por la edición fuente; [texto de licencia](MICROBIOLOGIA-LICENCIA.txt). Los créditos y enlaces de cada imagen están incorporados en el HTML y en [microbe-image-credits.json](microbe-image-credits.json). Estas condiciones de las imágenes no otorgan derechos sobre los contenidos de MensaGuide. Se omitió una fotografía candidata de Trichomonas que mostraba un copyright de tercero sin autorización independiente confirmada.

Los JPEG están incorporados **sin modificación**, recorte, redimensionado ni retoque; el tamaño en pantalla se adapta con CSS y conserva toda la imagen. Se tradujeron las leyendas al español y se conserva la leyenda original consultable. Los hashes SHA-256 de los archivos originales y los incorporados coinciden.

## Comprobaciones

Las 18 imágenes se decodifican con sus dimensiones originales. Se compararon los textos de sección de las 890 fichas contra el HTML anterior; la base clínica completa permanece idéntica. Se probaron búsqueda, filtro, ficha, ampliación, Escape y favoritos, sin errores JavaScript ni solicitudes externas durante esos recorridos. Se revisaron visualmente las 18 fotografías, la lista de miniaturas y la ficha.

Informe: [microbe-photos-validation.json](microbe-photos-validation.json). La colección es inicial y no implica que haya fotografía para todos los microorganismos. Las limitaciones anteriores de las calculadoras se mantienen.
