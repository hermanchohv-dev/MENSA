# Versión ligera de MensaGuide

Descarga [MensaGuide-escritorio-ligero.html](MensaGuide-escritorio-ligero.html) con **Download raw file**. Ocupa 44.859.890 bytes (44,9 MB), frente a 97.380.833 bytes (97,4 MB) de la versión anterior: **53,9 % menos**.

Las 621 referencias fotográficas de las 435 fichas se conservan. Se preparan copias WebP de calidad 76 (parámetro del codificador en escala 0–100) y lado máximo de 960 píxeles. Las imágenes menores no se amplían. No se recortan ni retocan. La reducción permite conservar una calidad razonable para la consulta habitual, con menor detalle al ampliar imágenes que antes tenían más resolución. La versión anterior permanece disponible en [MensaGuide-escritorio-Wikipedia.html](MensaGuide-escritorio-Wikipedia.html).

Se mantienen la identificación, las leyendas, los autores, las licencias y los enlaces de origen de cada fotografía. La indicación de cambios en cada ficha describe la compresión de esta entrega. Cada imagen guarda el hash y las dimensiones de la versión anterior para su trazabilidad. El [informe de compresión](image-compression-report.json) recoge tamaños y hashes.

La base clínica, los cálculos y las herramientas de escritorio permanecen iguales. El HTML sigue siendo autónomo y no necesita conexión para consultar las imágenes. La etiqueta «LIGERA» identifica esta entrega y se conserva la fecha de datos solicitada: 10/10/2026.

Se comprobaron las 621 imágenes en Chromium, sus dimensiones y hashes, la conservación de las fichas y metadatos, la búsqueda, el filtro, el selector, el visor ampliado, su cierre y la navegación a imágenes con la red desconectada. Se compararon visualmente muestras de microscopía, cultivos y tejidos con la versión anterior. No se registraron errores JavaScript ni solicitudes externas durante estas pruebas. Detalles en [light-validation.json](light-validation.json). Las pruebas no constituyen validación clínica.
