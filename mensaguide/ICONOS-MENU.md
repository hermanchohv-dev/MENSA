# Iconos del menú lateral

Descarga [MensaGuide-escritorio-iconos.html](MensaGuide-escritorio-iconos.html) con **Download raw file**. Conserva la versión ligera y los enlaces CIMA junto a las marcas.

Las 12 categorías tienen un pequeño icono SVG propio: cápsula y comprimido para antimicrobianos; microorganismos en magenta; termómetro y persona para síndromes; persona con escudo para profilaxis; jeringa para vacunas; persona aislada para aislamiento; maletín médico para utilidades; libro para abreviaturas; estrella para favoritos; escudo con marca de verificación; símbolo de información para esta versión; y balanza para comparar fármacos. Los primeros motivos y colores siguen la referencia visual aportada. Se mantienen las tarjetas y el fondo azul del menú.

Los iconos están integrados, funcionan sin conexión y añaden solo 4.579 bytes al HTML (aproximadamente 4,6 kB). Son decorativos para los lectores de pantalla, mientras las etiquetas originales siguen identificando cada botón. No modifican datos clínicos, cálculos, imágenes, créditos ni enlaces de CIMA.

Se verificaron las 12 categorías, la ausencia de desbordamiento en los botones de escritorio, la persistencia de iconos al navegar, el filtro de fotografías, los enlaces CIMA del encabezado y la ausencia de errores JavaScript. Detalles en [menu-icons-validation.json](menu-icons-validation.json). El código está en [menu-icons.js](menu-icons.js).
