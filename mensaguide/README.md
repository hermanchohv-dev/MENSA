# MensaGuide para navegador

Descarga `MensaGuide.html` mediante el botón **Download raw file** de GitHub y ábrelo en un navegador moderno. Es un archivo autónomo; no necesita instalar dependencias.

Incluye 1.961 registros españoles de MensaGuide 26.40 (344), 88 calculadoras y 11 tablas. Siete módulos de cálculo siguen pendientes. No es una versión oficial ni una réplica completa validada clínicamente.

Consulta [LEEME.md](LEEME.md) para el uso y [ANALISIS.md](ANALISIS.md) para el alcance y las limitaciones. El informe [release-validation.json](release-validation.json) distingue pruebas automatizadas y observaciones aportadas desde la app original.

## Versión web 3

La bibliografía aparece al final de la ficha. En Antimicrobianos, el selector «Buscar por» permite elegir principio activo, nombre comercial o todo el contenido. Los resultados muestran las presentaciones comerciales para identificar el medicamento. La búsqueda utiliza los nombres de la base aportada y el alias Tazocel → piperacilina/tazobactam, transcrito previamente por el usuario. No es un catálogo comercial exhaustivo ni actualizado por país.

Se comprobó la bibliografía al final en las 200 fichas que contienen ese campo, búsquedas por Harvoni, Isentress y Tazocel, apertura de la ficha correspondiente, búsqueda por principio activo y presentación móvil. Detalles en [v3-validation.json](v3-validation.json).
